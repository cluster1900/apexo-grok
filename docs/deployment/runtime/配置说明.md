# Runtime 配置说明

## 配置加载链

Rust 实现必须按以下顺序加载，后者覆盖前者：

1. 内置默认值。
2. global/project 配置文件。
3. remote/managed config。
4. `OPENCODE_*` 环境变量。
5. CLI flag / Desktop sidecar 注入 env。

## 关键环境变量

| 变量 | 用途 |
|---|---|
| `OPENCODE_SERVER_USERNAME` | Basic Auth 用户名，Desktop sidecar 默认 `opencode`。 |
| `OPENCODE_SERVER_PASSWORD` | Basic Auth 密码，Desktop sidecar 随机生成。 |
| `OPENCODE_CLIENT` | `cli/app/desktop`，影响 question tool 和 UI 行为。 |
| `OPENCODE_DB` | SQLite 路径或 `:memory:`。 |
| `XDG_STATE_HOME` | Desktop sidecar userData/state 路径。 |
| `OPENCODE_PURE` | 禁用外部插件。 |
| `OPENCODE_DISABLE_EMBEDDED_WEB_UI` | Desktop 禁用 server 内嵌 Web UI。 |

## Secret 规则

- Provider API key、OAuth token、MCP header secret 只来自 env/secret manager。
- 配置文件不得保存明文 secret。
- 日志、trace、prompt、命令行不得输出 secret。

## Desktop sidecar

- main 进程启动 sidecar 时传入 hostname、port、password、userDataPath、needsMigration。
- sidecar 设置 `OPENCODE_SERVER_USERNAME/PASSWORD` 和 `XDG_STATE_HOME`。
- migration progress 通过 IPC 回传，ready 后通过 `/global/health` 轮询确认。
