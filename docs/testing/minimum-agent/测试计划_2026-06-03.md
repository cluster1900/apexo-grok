## 3. M1 测试设计

### 3.1 单元测试

- `SessionId`、`TurnId`、`MessageId`、`PartId` 构造校验：前缀、body 长度、body 字符集。
- `TraceId` 构造校验：内部 `trc_`、外部 W3C trace id / `traceparent` 解析、非法 trace 拒绝。
- `ModelRef` 与 `FinishReason` 构造校验：非法 provider/model/variant、未知 finish reason 拒绝。
- `Session` 创建、追加 user message、开始 assistant message。
- `SessionProjector` 投影 `TextDelta`、`Finished`、`ProviderError`；M1 `Finished` 不生成 usage part。
- 非法状态转换拒绝，例如 finish 后继续追加 text。

### 3.2 场景测试

```text
create session
  -> append user message
  -> start assistant message
  -> project text delta
  -> project finish
  -> assert assistant text + finish reason
```

M1 不允许出现：

- CLI 参数解析。
- provider HTTP。
- filesystem / storage。
- tool registry。

## 4. M2 测试设计

- E2E：`opencode run --mock "hello"` 输出固定文本，退出码 0。
- E2E：fake provider error 时 CLI 非 0，stderr 包含语义错误码。
- 功能完整性：确认不读 API key、不写 session 文件、不加载 plugin。
- 场景：application command -> fake stream -> projector -> stdout。

## 5. M3 测试设计

- `AGENTS.md` / `CONTEXT.md` 只从 workspace 内读取。
- `.opencode/skill/**/SKILL.md` 和 `.opencode/skills/**/SKILL.md` frontmatter 可解析。
- 非法 skill frontmatter 产生 typed error，不进入 prompt。
- `SkillIndex` 只包含 name / description / location，不包含完整正文。
- `MemorySnapshot` 只包含 last N turns、facts、anchors，不包含 secret。
- ContextPack block 顺序、source、trust level 可断言。

## 6. M4 测试设计

- repository 保存 session/message/part。
- `--session <id>` 恢复历史。
- 存储失败时 application 返回错误，不产生半写入状态。
- JSON repository 如作为过渡实现，必须在测试中覆盖 schema version。
- context metadata / memory snapshot 恢复后可重建 ContextPack。

## 7. M5 测试设计

- SSE / JSON fixture 转换为 `LlmEvent::TextDelta`、`Finished`、`ProviderError`。
- API key 只从 env 注入，错误信息不打印 secret。
- provider adapter 不直接写 session。
- 协议 fuzz 覆盖畸形 frame、缺字段、超长 delta。
- 手工真实 provider 验证可单独出报告，不作为默认 CI 门禁。

## 8. M6 测试设计

- provider/tool/prompt/memory/mcp capability schema 可解析。
- capability 权限上限必须被校验。
- 越权覆盖 workspace guard、permission、secret redaction、ContextPack 顺序时拒绝。
- schema fuzz 覆盖缺字段、未知 capability、权限升级、版本不兼容。

## 9. M7 测试设计

- `WorkspaceRoot` 规范化和 containment。
- `read` workspace 内文件成功。
- `read ../outside`、软链越界拒绝。
- `.env*` 默认 ask 或拒绝。
- `grep/glob` 输出截断并包裹 `<untrusted_input>`。
- `skill` tool 默认 ask，reject 后不读取 skill 正文。
- `skill` tool 输出 `<skill_content>`，并标记为不可信内容。
- Agent Eval smoke：模型要求读取文件时选择 read/grep，而不是凭空回答。

## 10. M8 测试设计

- disabled MCP 不连接。
- local stdio MCP server 启动失败只记录 `mcp.failed`，不阻塞主 run。
- `tools/list` 转换成命名空间化 `ToolDefinition`。
- MCP tool call 必须经过 permission evaluator。
- MCP resource read 进入 ContextPack，并包裹 `<untrusted_input>`。
- timeout / cancellation 关闭 MCP 子进程。

## 11. M9 测试设计

- `edit/write` 默认 ask。
- `shell` 默认 ask。
- reject 后不写文件、不启动进程。
- once / always 仅在当前 scope 生效。
- shell timeout 产生 `ToolExecutionError`。
- dangerous 命令默认 deny 或二次确认。
