# 外部集成：GitHub、Slack 与编辑器开发设计

## 1. 目标与非目标

- 目标：迁移 GitHub Action、Slack bot、VS Code extension、Zed extension、外部事件到 session/CLI/SDK 的 adapter。
- 非目标：重写外部平台本身和云端账号系统。

## 2. 背景

上游入口：`github/*`、`sdks/vscode/*`、`packages/extensions/zed/*`、`packages/slack/*`。

## 3. 领域模型

| 聚合/对象 | 说明 |
|---|---|
| `IntegrationInstallation` | platform、repo/workspace、permissions、token ref。 |
| `ExternalActor` | GitHub/Slack/editor user。 |
| `ExternalReference` | issue/PR/comment/review/file/range/thread。 |
| `IntegrationCommand` | `/opencode`、`/oc`、editor command、Slack command。 |

## 4. 用例编排

- GitHub event -> trigger parse -> actor permission -> resolve issue/PR/diff -> session prompt -> branch/PR/comment/share。
- editor command -> active selection/file reference -> terminal/CLI/SDK append prompt。
- Slack event -> thread/context -> session prompt -> reply。

## 5. 关键边界

- `IntegrationAdapter`、`ExternalReferenceResolver`、`IntegrationReplyPort`、`IntegrationDedupeStore`。

## 6. 错误模型

`IntegrationUnauthorized`、`ExternalEventIgnored`、`ReferenceResolutionFailed`、`PlatformRateLimited`、`ReplyFailed`。

## 7. 测试与验收

- GitHub mock events、review comment diff context、VS Code keybindings/file refs、Zed manifest sync、Slack event contract。
