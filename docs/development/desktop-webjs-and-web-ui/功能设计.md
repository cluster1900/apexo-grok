# Desktop WebJS 与 Web UI 开发设计

## 1. 目标与非目标

- 目标：保留 Electron/WebJS desktop、sidecar 启停、preload API、native picker/clipboard/updater/deeplink、Web app、UI package、Storybook。
- 非目标：一次性重写 WebJS UI 为 Rust。

## 2. 背景

上游入口：`packages/desktop/*`、`packages/app/*`、`packages/ui/*`、`packages/storybook/*`。

## 3. 领域模型

| 对象 | 说明 |
|---|---|
| `DesktopSidecar` | Rust server 进程、health、auth、migration progress、shutdown。 |
| `PreloadApi` | renderer 可调用的 native API 白名单。 |
| `WebSessionView` | session/message/tool/permission/terminal/diff/file/settings 状态投影。 |
| `UiComponentContract` | markdown/diff/file/tool/message 组件 contract。 |

## 4. 用例编排

- app start -> shell env/proxy/cert -> sidecar start -> migration progress -> health -> renderer SDK。
- renderer prompt/settings/terminal/file -> SDK/WS/preload -> Rust sidecar。
- updater/deeplink/native picker/clipboard -> preload IPC -> main process adapter。

## 5. 关键边界

- `SidecarSupervisor`、`DesktopPreloadBridge`、`NativeDialogPort`、`ClipboardPort`、`UpdaterPort`、`WebSdkClient`。

## 6. 错误模型

`SidecarStartFailed`、`MigrationTimeout`、`PreloadRequestDenied`、`NativePickerFailed`、`UpdateCheckFailed`、`WebSdkDisconnected`。

## 7. 测试与验收

- preload contract、sidecar lifecycle、Web app Playwright session/prompt/diff/permission/terminal/settings、UI story snapshots。

## 8. 上游细节基线（2026-05-27 回补）

### 8.1 Sidecar 管理

Desktop main process 通过 Electron `utilityProcess.fork` 启动 sidecar，等待 ready/health，监听 exit，支持 kill/relaunch，并向 renderer 暴露默认 server URL、初始化步骤和 SQLite migration progress。Rust sidecar 需要提供等价 ready frame、password/auth、port fallback 和健康检查。

### 8.2 Auto Updater

`updater.ts` 配置 autoUpdater channel，支持 `runUpdater(alertOnFail)`、`checkUpdate()`、`installUpdate()`、下载完成后询问是否 restart。错误需要写 desktop debug log 并通过 preload API 返回。

### 8.3 Deeplink

必须处理 `opencode://open-project?directory=...` 和 `opencode://new-session?directory=...&prompt=...`。main process 收集启动参数和 second-instance URL，renderer 通过 `consumeInitialDeepLinks`、`onDeepLink` 消费；无效 URI 或空 directory 要安全忽略。

### 8.4 Cert / Proxy

Desktop 启动时加载 shell env、系统证书和代理设置，设置 `proxy-bypass-list`，sidecar 也注入 `http_proxy`、`https_proxy`、`no_proxy` 和 default CA certificates。相关值不得写入普通日志。

### 8.5 Typed Preload IPC

preload 只暴露 typed allowlist：sidecar、CLI install、window config、deep links、server URL、WSL/display backend、markdown parser、app/path resolver、store get/set/delete/clear/keys/length、native picker、open link/path、clipboard image、notification、window focus/show、zoom/pinch、titlebar、desktop menu、updater、background color、debug logs、fatal renderer error。新增 IPC 必须先改 preload types 和 main handler 测试。

### 8.6 M1 Sidecar Contract — 2026-05-28

调研结论见 `docs/research/m1-interface-foundation/调研报告_2026-05-28.md`。M1 先在 `opencode_desktop` 固定 WebJS sidecar 的 JSON contract：

| 类型 | 字段 / 取值 | 说明 |
|---|---|---|
| `InitStep` | `server_waiting`、`sqlite_waiting`、`done` | 对齐 preload `awaitInitialization(onStep)` 的初始化进度。 |
| `ServerReadyData` | `url`、`username`、`password` | ready payload；`Debug` 必须脱敏 password。 |
| `MigrationProgress` | `0..=100` | SQLite migration progress 百分比。 |
| `SidecarErrorMessage` | 非空 string | error payload；反序列化时拒绝空字符串。 |
| `SidecarEvent` | `ready`、`sqlite`、`stopped`、`error` | sidecar -> Electron main 的最小事件帧。 |

M1 不实现 Electron utility process、preload bridge、native picker/clipboard/updater 或 Web app smoke；这些仍归后续 Desktop prototype 和 Playwright/Electron contract tests。
