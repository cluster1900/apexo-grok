# Desktop WebJS 与 Web UI接口设计

## 1. 接口形态

- Electron main/preload IPC。
- Preload API: initialization、directory/file/save picker、clipboard image、update、store。
- WebJS SDK/SSE/WS。
- UI package components and Storybook。

## 2. 请求 / 响应 schema

- InitStep/SidecarReady。
- NativePickerRequest/Result。
- TerminalFrame。
- WebSessionProjection and settings state。

## 3. 错误码

- SidecarStartFailed
- MigrationTimeout
- PreloadRequestDenied
- NativePickerFailed
- UpdateCheckFailed
- WebSdkDisconnected

## 4. 兼容性

- 外部路径、operationId、CLI 参数、配置字段和事件名以调研附件与上游源码为基线，Rust 实现不得无迁移说明地改名。
- 新增字段必须显式版本化；删除字段必须先提供兼容层和 progress 记录。
- 所有外部输入进入 application 前必须 schema 校验；外部文本进入 prompt 前必须截断并包裹 `<untrusted_input>`。

## 5. 示例

- 成功：desktop 启动 sidecar，awaitInitialization 返回 url/username/password，renderer 通过 SDK 加载 session timeline。
- 失败：sidecar health timeout 返回 MigrationTimeout/SidecarStartFailed，renderer 显示 fatal error 且无孤儿进程。

## 6. Desktop/WebJS Contract 下沉 — 2026-05-27

### Preload and ElectronAPI groups

除了 initialization/picker/clipboard/update/store，还必须覆盖：kill sidecar、install CLI、default server、WSL/display backend、parse markdown、check app exists、open path、window focus、zoom/pinch、titlebar/menu/loading/background/debug logs/fatal error。

### IPC/sidecar protocol

- sidecar start/stop/ready/error/sqlite migration progress/health timeout。
- oc://renderer 安全协议和 renderer preload bootstrap。
- desktop menu actions、accelerators、native titlebar/window focus、deeplink queue、updater download/install state。
- renderer platform contract must expose OS, shell, WSL/display backend, app version, CLI path and server URL/auth.
