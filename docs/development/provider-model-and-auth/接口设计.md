# Provider、Model 与认证接口设计

## 1. 接口形态

- Provider auth: list/authorize/callback/logout。
- Model catalog: provider/model list、status、capability、cost、variant。
- LLM streaming: text/reasoning/tool-call/usage/error frames。
- packages/llm route/provider/protocol exports parity。

## 2. 请求 / 响应 schema

- ProviderID/ModelID newtype。
- ModelProfile: context/input/output limits、tool/vision/reasoning support、cost。
- CredentialRef: env or secret manager reference only。

## 3. 错误码

- ProviderNotFound=404
- ModelNotFound=404
- AuthRequired=401/400
- OAuthStateInvalid=400
- RateLimited=429 retryable
- StreamFrameInvalid=502

## 4. 兼容性

- 外部路径、operationId、CLI 参数、配置字段和事件名以调研附件与上游源码为基线，Rust 实现不得无迁移说明地改名。
- 新增字段必须显式版本化；删除字段必须先提供兼容层和 progress 记录。
- 所有外部输入进入 application 前必须 schema 校验；外部文本进入 prompt 前必须截断并包裹 `<untrusted_input>`。

## 5. 示例

- 成功：POST /provider/{providerID}/oauth/authorize 返回授权 URL/method，callback 成功后 provider.list 显示可用模型。
- 失败：OAuth state 不匹配返回 OAuthStateInvalid=400；provider stream frame 无法解析返回 StreamFrameInvalid=502。

## 6. Provider Dialog/Auth Contract — 2026-05-27

- HTTP: provider.list、provider.auth、provider.oauth.authorize、provider.oauth.callback、control auth.set、auth.remove。
- Auth methods include api and oauth flows; OAuth may require prompt/select/when metadata before authorize/callback。
- Connected provider source must distinguish env、api、config、custom for UI display and logout behavior。
- Custom provider form covers base URL、API key env/ref、model id/name、reasoning/tool/vision flags、cost/limit metadata and validation errors。
- Model visibility toggles map to config enabled/disabled providers/models and must not mutate provider catalog source data.
