# minimum-agent 数据设计

## 1. 数据形态

M4 需要持久化 session。正式方案倾向 SQLite，但 SQLite crate 和 migration 工具需要单独 research；在依赖未确认前，本设计只定义逻辑 schema，并允许 M4 用临时 JSON repository 验证 repository 边界。

## 2. 逻辑表

### `sessions`

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | text | `ses_` 前缀。 |
| `workspace_root` | text | 规范化绝对路径。 |
| `title` | text nullable | 后续 title agent 生成。 |
| `agent` | text | M4 起固定 `build`。 |
| `provider_id` | text | provider id。 |
| `model_id` | text | model id。 |
| `created_at` | datetime utc | 创建时间。 |
| `updated_at` | datetime utc | 更新时间。 |
| `archived_at` | datetime utc nullable | 归档时间。 |

### `turns`

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | text | `turn_` 前缀。 |
| `session_id` | text | 所属 session。 |
| `trace_id` | text | 本轮 trace。 |
| `status` | enum | `running/completed/failed/cancelled`。 |
| `created_at` | datetime utc | 创建时间。 |
| `completed_at` | datetime utc nullable | 完成时间。 |

### `messages`

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | text | `msg_` 前缀。 |
| `session_id` | text | 所属 session。 |
| `turn_id` | text nullable | 所属 turn。 |
| `role` | enum | `user/assistant/tool/system`。 |
| `created_at` | datetime utc | 创建时间。 |
| `metadata` | json | 非敏感元数据。 |

### `parts`

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | text | `part_` 前缀。 |
| `message_id` | text | 所属 message。 |

| `created_at` | datetime utc | 创建时间。 |

### `context_snapshots`

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | text | `ctx_` 前缀。 |
| `session_id` | text | 所属 session。 |
| `turn_id` | text nullable | 所属 turn。 |
| `schema_version` | int | ContextPack schema 版本。 |

### `permission_rules`

| 字段 | 类型 | 说明 |
|---|---|---|

| `action` | enum | `allow/deny/ask`。 |

### `mcp_servers`

M8 起登记 local stdio MCP 状态。M4 的 JSON repository 可以先不实现该表。

| 字段 | 类型 | 说明 |
|---|---|---|
| `name` | text | server name。 |

| `enabled` | bool | 是否启用。 |
| `timeout_ms` | int | 请求 timeout。 |
| `last_status` | enum | `connected/disabled/failed`。 |

## 3. 内存结构

### `RunState`

按 `session_id` 记录当前运行：

- cancellation token。
- current turn id。
- current step index。
- pending permission request。
- active tool calls。

同一 session 不允许并发两个 run。

### `PluginRegistry`

M6 内存 registry：

- provider adapters。
- tool definitions。
- prompt assets。
- event subscribers。

Registry 保存 capability 元数据，不保存插件内部可变状态。

### `ContextPack`

M3 起在内存中构造：

- environment block。
- instruction blocks。
- skill index block。
- memory snapshot block。
- M8 起可追加 mcp resource block。

M4 起保存 context metadata，便于 session 恢复后重建；不长期保存未截断的外部原文。

## 4. 生命周期

- ContextPack：每次 run 构造，M4 起保存 metadata。
- Session：首次 `run` 创建，用户指定 `--session` 时恢复。
- Turn：每次用户 prompt 创建。
- Message：user/assistant/tool/system 产生时创建。
- Part：stream delta 或 tool state 变化时追加或更新。
- PermissionRule：CLI 参数、配置或用户 always 回复产生。

删除策略：

- M1/M2 不提供删除命令。
- archive 后续通过 API/TUI 实现。

## 5. 索引与查询模式

必需索引：

- `sessions(id)`
- `sessions(updated_at)`
- `turns(session_id, created_at)`
- `messages(session_id, created_at)`
- `parts(message_id, created_at)`
- `parts(session_id, created_at)`
- `context_snapshots(session_id, created_at)`
- `permission_rules(scope, scope_id, permission)`

常见读路径：

- 通过 session id 加载完整上下文。
- 按 session id 读取最近 messages/parts 组成 prompt。
- 按 session id 读取最近 context metadata 重建 MemorySnapshot。
- 按 session id 查询 run status。
- 按 scope 查询 permission rules。

## 6. 迁移脚本

未定。SQLite 选型确认后，在 `docs/deployment/migration/` 增加：

- 初始 schema migration。
- rollback 脚本。
- schema version 记录。

如果 M4 先使用 JSON repository，必须记录 `schema_version`，并在 SQLite research 通过后补迁移方案；JSON repository 不作为长期存储承诺。

## 7. 数据安全

- secret 不写入任何表。
- prompt 中的外部内容只保存截断后的安全版本，原始长输出通过 tool output storage 独立管理。
- 命令输出超过限制时不直接塞入 part，应写入受控 truncation storage 并返回引用。
