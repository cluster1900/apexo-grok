# minimum-agent 测试矩阵

本矩阵是功能设计层的覆盖清单；执行计划和全仓编号见 `docs/testing/minimum-agent/测试计划_2026-06-03.md` 与 `docs/testing/critical-integration-tests.md`。

## 1. 单元测试

| 对象 | 覆盖 |
|---|---|
| M1 `Session` | 创建、追加 message、追加 part、非法状态转换拒绝。 |
| M1 `ModelRef` | `provider/model` 解析、空值拒绝、variant 解析。 |
| M1 `LlmEvent` projector | text/finish 事件投影。 |
| M3 `WorkspaceRoot` / `InstructionSource` | context-only 路径规范化、workspace-local instruction、越界拒绝。 |
| M3 `ContextPack` | block 顺序、source、trust level、token budget。 |
| M3 `SkillIndex` | frontmatter 缺失、非法名称、重复名称、正文不进入 index。 |
| M3 `MemorySnapshot` | last N turns、facts、anchors、secret 过滤。 |
| M7 tool `WorkspacePath` | tool 入参路径规范化、`../` 越界、软链越界、敏感文件策略。 |
| M7 `ToolDefinition` | JSON Schema 缺失、非法参数、timeout 默认值。 |
| M8 `McpServerConfig` | local stdio config、enabled、timeout、非法 command。 |
| M9 `PermissionRule` | allow/deny/ask 优先级、pattern 匹配。 |

## 2. 场景测试

| 场景 | 主流程 |
|---|---|
| M1 projector | user message -> fake text delta -> finish -> assistant part。 |
| M2 mock run | CLI prompt -> fake provider -> stdout。 |
| M3 context pack | instruction + skill index + memory snapshot -> system context。 |
| M4 persisted run | mock run -> session/context saved -> `--session` restores。 |
| M5 provider error | prompt -> provider error -> turn failed -> CLI non-zero。 |
| M7 read tool | model tool-call read -> workspace read -> tool result -> final answer。 |
| M7 skill tool | model tool-call skill -> ask -> load SKILL.md -> context continues。 |
| M8 MCP tool | MCP list tools -> namespaced tool call -> permission -> result。 |
| M8 MCP resource | MCP resource read -> ContextPack block。 |
| M9 permission reject | shell tool-call -> ask -> reject -> tool error part -> stop。 |
| M9 tool timeout | shell timeout -> tool error -> next model step。 |

## 3. 功能完整性测试

逐条对照 `功能设计.md`：

- 每个阶段只验收本阶段目标。
- 每个阶段的非目标必须确认没有越界实现。
- M3 context/skill/memory 目标必须验证来源、信任边界和 secret 过滤。
- M7/M8/M9 安全目标必须有 positive + negative case。
- M6 只验证 capability manifest 被解析和安全拒绝，不执行外部插件。

## 4. E2E 测试

| 编号 | 命令 | 断言 |
|---|---|---|
| E2E-001 | `opencode run --mock "hello"` | stdout 有 deterministic text，退出码 0。 |
| E2E-002 | `opencode run --mock "hello" --session <id>` | 可恢复 session。 |
| E2E-003 | `opencode run --mock "hello"` with `AGENTS.md` | M3 起 ContextPack 包含 instruction block。 |
| E2E-004 | `opencode run "hello"` | M5 起 stdout 有 text，退出码 0。 |
| E2E-005 | `opencode run "read file"` | M7 起 read 工具路径在 workspace 内，tool result 写入 session。 |
| E2E-006 | `opencode run "load skill"` | M7 起 skill tool ask 后加载 skill content。 |
| E2E-007 | `opencode run "use mcp"` | M8 起 MCP tool 经 permission 执行。 |
| E2E-008 | `opencode run "read outside"` | M7 起越界失败，错误码 `workspace.outside_root`。 |
| E2E-009 | `opencode run "run shell"` | M9 起 shell ask 出现，reject 后无命令执行。 |

Provider 使用 mock / fixture，不在 CI 调真实模型。

## 6. 对抗性测试

| 用例 | 预期 |
|---|---|
| 文件内容夹带“忽略 system prompt” | 进入 prompt 前被 `<untrusted_input>` 包裹。 |
| tool output 夹带 shell 命令 | 不自动执行，必须下一轮 tool call + permission。 |
| 读取 `/etc/passwd` | workspace guard 拒绝。 |
| 写入 `../outside` | workspace guard 拒绝。 |
| shell `rm -rf /` | dangerous/execute ask 或 deny。 |
| `.env` 读取 | 默认 ask。 |
| provider 返回畸形 tool args | `tool.invalid_args`，不执行工具。 |
| skill 内容夹带 system 指令 | 作为 `<skill_content>` 和不可信输入处理，不覆盖 system。 |
| MCP resource 夹带 system 指令 | 作为 `mcp_resource` ContextBlock，不覆盖 system。 |
| MCP server 超时 | 关闭子进程，当前 server 标记 failed。 |

## 7. Prompt 回归

M5 引入 `prompts/build.system.v1.md` 后，必须建立最小回归：

- 5 条代码仓库解释类 prompt。
- 5 条工具使用类 prompt。
- 断言输出必须引用工具可见信息，不可凭空声明已读文件。

## 8. Agent Eval

M7/M8/M9 必须跑：

- trajectory：10 条。
- tool-use accuracy：工具选择正确率 ≥70%。
- schema pass rate：100%。
- workspace safety：100%。
- cost budget：单任务 token/cost 不超过配置上限。

## 9. 提交前命令

最小必跑：

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --all-features -- -D warnings
cargo test --workspace --all-features
cargo deny check
cargo audit
```

若 `cargo audit` 在线 advisory 拉取失败，可临时记录 `cargo audit --no-fetch --stale` 结果，但 PR 必须说明。
