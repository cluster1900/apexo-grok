# minimum-agent 接口设计

## 1. 接口形态

M2 开始提供 mock CLI：

```bash
opencode run --mock <prompt> [options]
```

M5 开始提供真实 provider CLI：

```bash
opencode run <prompt> [options]
```

M7/M8 继续使用同一入口，增加 read / skill / MCP tool；M9 增加 write / shell 权限和工具开关。

不提供：

- HTTP API
- TUI API
- SDK
- MCP 管理 API
- plugin install API

## 2. CLI 请求 schema

| 字段 | 类型 | 必填 | 默认 | 校验 |
|---|---|---|---|---|
| `prompt` | string | 是 | 无 | 非空，最大长度由配置控制。 |
| `--workspace` | path | 否 | 当前目录 | M3 起必须生成 `WorkspaceRoot`。 |
| `--session` | string | 否 | 新建 | M4 起支持；必须匹配 `ses_` 前缀。 |
| `--model` | string | 否 | config 默认 | M5 起支持；格式 `provider/model`。 |
| `--agent` | string | 否 | `build` | M5 起支持；最小实现只允许 `build`。 |
| `--format` | enum | 否 | `text` | M2 起支持 `text`，预留 `json`。 |
| `--no-context` | bool | 否 | false | M3 起禁用 instruction / skill index / memory snapshot，用于调试。 |
| `--allow` | string[] | 否 | 空 | M7 起 skill/read/MCP 可用，M9 起 write/shell 可用。 |
| `--deny` | string[] | 否 | 空 | M7 起权限规则。 |
| `--ask` | string[] | 否 | 空 | M7 起权限规则。 |
| `--no-tools` | bool | 否 | false | M7 起禁用工具循环。 |
| `--no-mcp` | bool | 否 | false | M8 起禁用 MCP Lite。 |

## 3. CLI 响应 schema

### 成功 text 输出

```text
<assistant text stream>
```

退出码：`0`。

### 失败输出

```text
error: <code>
detail: <human readable message>
session: <session_id if available>
trace: <trace_id>
```

退出码：非 `0`。

## 4. 内部 Provider 请求

```rust
struct LlmRequest {
    trace_id: TraceId,
    model: ModelRef,
    context: ContextPack,
    system: Vec<PromptPart>,
    messages: Vec<LlmMessage>,
    tools: Vec<ToolDefinition>,
    tool_choice: ToolChoice,
    generation: GenerationOptions,
}
```

`LlmEvent`：

| 事件 | 字段 |
|---|---|
| `TextDelta` | `message_id?`, `text` |
| `ReasoningDelta` | `text` |
| `ToolCallDelta` | `tool_call_id`, `name?`, `arguments_delta` |
| `ToolCallFinished` | `tool_call_id`, `name`, `arguments_json` |
| `UsageDelta` | `input_tokens?`, `output_tokens?`, `cache_tokens?` |
| `Finished` | `finish_reason` |
| `ProviderError` | `code`, `message`, `retryable` |

M1 只实现 `TextDelta`、`Finished`、`ProviderError`；M5-M9 再按 [`../../architecture/events.md`](../../architecture/events.md) 打开其它事件。

## 5. ContextPack 协议

```rust
struct ContextPack {
    trace_id: TraceId,
    session_id: SessionId,
    blocks: Vec<ContextBlock>,
    token_budget: TokenBudget,
}

struct ContextBlock {
    kind: ContextBlockKind,
    source: ContextSource,
    trust: TrustLevel,
    content: String,
}
```

`ContextBlockKind`：

| kind | 阶段 | 来源 |
|---|---|---|
| `environment` | M3 | workspace metadata。 |
| `instruction` | M3 | `AGENTS.md` / `CONTEXT.md`。 |
| `skill_index` | M3 | skill frontmatter。 |
| `memory_snapshot` | M3/M4 | session summary / last N turns / anchors。 |
| `mcp_resource` | M8 | MCP resource read。 |

除 `environment` 外，外部内容进入 provider 前必须保留 source，并按需要包裹 `<untrusted_input>`。

## 6. Skill 协议

```rust
struct SkillDefinition {
    name: SkillName,
    description: Option<String>,
    location: WorkspacePath,
    content: String,
}
```

M3 只使用 name / description / location 生成 skill index。M7 的 `skill` tool 才能加载完整 content。

## 7. Tool 协议

```rust
struct ToolDefinition {
    name: ToolName,
    description: String,
    input_schema: JsonSchema,
    permission_level: PermissionLevel,
    timeout_ms: u64,
}
```

MCP tool 进入 registry 前必须命名空间化：

```text
mcp:<server_name>:<tool_name>
```

Tool result：

```rust
enum ToolResult {
    Text { output: String },
    Json { value: serde_json::Value },
    Error { message: String },
}
```

## 8. MCP Lite 协议

M8 配置只支持 local stdio：

```rust
struct McpServerConfig {
    name: McpServerName,
    command: Vec<String>,
    enabled: bool,
    timeout_ms: u64,
}
```

状态：

```rust
enum McpStatus {
    Connected,
    Disabled,
    Failed { message: String },
}
```

MCP Lite port：

```rust
trait McpGateway {
    fn status(&self) -> HashMap<McpServerName, McpStatus>;
    fn tools(&self) -> Vec<ToolDefinition>;
    fn call_tool(&self, call: ToolCall, context: ToolContext) -> ToolResult;
    fn resources(&self) -> Vec<McpResourceRef>;
    fn read_resource(&self, resource: McpResourceRef) -> ContextBlock;
}
```

## 9. Permission 响应

M7 起 CLI ask 交互：

```text
tool shell requests execute:
  pattern: cargo test
  description: Run test suite

[o] once  [a] always  [r] reject
```

内部响应：

```rust
enum PermissionReply {
    Once,
    Always,
    Reject,
}
```

## 10. 错误码

| 错误码 | 触发 |
|---|---|
| `config.invalid` | 配置解析或校验失败。 |
| `config.secret_in_file` | secret 出现在配置文件。 |
| `session.not_found` | 指定 session 不存在。 |
| `session.busy` | session 已有 run 在执行。 |
| `provider.unavailable` | provider 未配置或不可用。 |
| `provider.protocol` | provider stream 无法解析。 |
| `context.invalid` | ContextPack 构造失败。 |
| `instruction.invalid` | instruction 文件读取或解析失败。 |
| `skill.invalid` | skill frontmatter 或正文非法。 |
| `skill.not_found` | 请求加载的 skill 不存在。 |
| `workspace.outside_root` | 路径越界。 |
| `permission.denied` | 权限规则拒绝。 |
| `permission.rejected` | 用户拒绝 ask。 |
| `tool.invalid_args` | tool 参数 schema 失败。 |
| `tool.timeout` | tool 执行超时。 |
| `mcp.config_invalid` | MCP local stdio 配置非法。 |
| `mcp.failed` | MCP server 启动或协议失败。 |
| `mcp.resource_not_found` | MCP resource 不存在。 |

## 11. 兼容性

当前仓库还没有真实 CLI agent API；本设计不破坏既有客户端。

后续 HTTP/SDK 必须以本接口中的 domain DTO 为源，不允许单独发明另一套 session/message/tool schema。

## 12. 示例

成功：

```bash
opencode run "Explain this repository" --model openai/gpt-4o-mini
```

失败：

```bash
opencode run "Read /etc/passwd" --workspace /Users/hawk_wu/Desktop/opencode-rs
```

```text
trace: trc_...
```
