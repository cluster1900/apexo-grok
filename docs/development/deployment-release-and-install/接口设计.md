# 部署、发布与安装接口设计

## 1. 接口形态

- install flags --version/--binary/--no-modify-path。
- Nix flake packages/overlays。
- GitHub workflows/actions。
- container build script。
- release/publish/sign/sync-zed scripts。

## 2. 请求 / 响应 schema

- PlatformTarget: os、arch、libc、cpu baseline。
- ReleaseArtifact: kind、version、target、checksum、signature。
- DependencyPatch: package、reason、replacement decision。

## 3. 错误码

- UnsupportedPlatform
- ArtifactNotFound
- ChecksumMismatch
- SigningFailed
- PublishConflict

## 4. 兼容性

- 外部路径、operationId、CLI 参数、配置字段和事件名以调研附件与上游源码为基线，Rust 实现不得无迁移说明地改名。
- 新增字段必须显式版本化；删除字段必须先提供兼容层和 progress 记录。
- 所有外部输入进入 application 前必须 schema 校验；外部文本进入 prompt 前必须截断并包裹 `<untrusted_input>`。

## 5. 示例

- 成功：install --version 1.2.3 在 darwin-arm64 选择 opencode-darwin-arm64.zip，校验 checksum 后安装到 $HOME/.opencode/bin。
- 失败：linux-x64 无 AVX2 选择 baseline artifact；unsupported OS/arch 返回 UnsupportedPlatform。

## 6. Installer/Release Contract — 2026-05-27

- Installer flags: --version/VERSION env, --binary, --no-modify-path, help, unknown option warning.
- Platform target: darwin/linux/windows x64/arm64, Linux musl detection, x64 AVX2 baseline, Rosetta arm64 correction, archive extension zip/tar.gz.
- PATH modification: shell rc detection, no modification when disabled, idempotent install dir $HOME/.opencode/bin.
- Nix: overlay packages opencode、opencode-desktop、node_modules_updater, hash updater scripts.
- Release: publish/sign/windows signing/notarize, GitHub release artifact naming, container image names/tags/build args, workflow permissions/secrets/artifacts.
