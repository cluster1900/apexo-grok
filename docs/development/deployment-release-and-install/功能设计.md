# 部署、发布与安装开发设计

## 1. 目标与非目标

- 目标：迁移 install、release scripts、CI workflow、Nix、container images、dependency patches、signing/updater/publish。
- 非目标：业务功能实现本身。

## 2. 背景

上游入口：`install`、`flake.nix`、`nix/*`、`.github/workflows/*`、`script/*`、`packages/containers/*`、`patches/*`。

## 3. 领域模型

| 聚合/对象 | 说明 |
|---|---|
| `InstallerPlan` | version、binary path、install dir、PATH policy、platform。 |
| `ReleaseArtifact` | artifact kind、version、platform target、checksum、signature。 |
| `BuildPipeline` | CI job、container image、publish/sign step。 |
| `DependencyPatch` | patched dependency、reason、Rust/WebJS replacement。 |

## 4. 用例编排

- install -> detect OS/arch/libc/CPU baseline -> choose artifact -> verify -> install -> optional PATH。
- release -> build matrix -> sign/notarize -> publish GitHub/S3/Nix/container/extension -> rollback manifest。
- dependency patch audit -> decide keep/remove/replace -> CI drift check。

## 5. 关键边界

- `PlatformDetector`、`InstallerPlanner`、`ArtifactPublisher`、`ReleaseManifestStore`、`SigningPort`。

## 6. 错误模型

`UnsupportedPlatform`、`ArtifactNotFound`、`ChecksumMismatch`、`SigningFailed`、`PublishConflict`。

## 7. 测试与验收

- local binary install、no PATH modification、Nix derivation metadata、container build script, release manifest diff。
