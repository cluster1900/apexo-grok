# Cloud Console、Stats 与 Enterprise 开发设计

## 1. 目标与非目标

- 目标：保留 Console、Stats、Enterprise、Function、SST infra 的 contract：account/API key/billing/usage/share/docs proxy/stats lake/GitHub App。
- 非目标：本阶段不承诺全部云产品用 Rust 重写。

## 2. 背景

上游入口：`packages/console/*`、`packages/stats/*`、`packages/enterprise/*`、`packages/function/*`、`infra/*`、`sst.config.ts`。

## 3. 领域模型

| 聚合/对象 | 说明 |
|---|---|
| `CloudAccount` | account、workspace、API key、billing 状态。 |
| `UsageReport` | provider/model/token/cost/latency/geo。 |
| `SharedSessionView` | enterprise/cloud share 的可访问视图。 |
| `DeploymentStage` | dev/staging/prod 资源命名和 secret scope。 |

## 4. 用例编排

- local usage -> outbox -> cloud ingest -> stats lake/projector。
- share -> local policy -> remote create/update/remove -> enterprise share route。
- GitHub App/function -> JWT/API -> integration adapter -> session/action。

## 5. 关键边界

- `CloudSyncPort`、`UsageSinkPort`、`ShareRemotePort`、`CloudSecretStore`、`FunctionApiAdapter`。

## 6. 错误模型

`CloudAuthRequired`、`SharePolicyDenied`、`UsageIngestConflict`、`CloudServiceUnavailable`、`SecretResolutionFailed`。

## 7. 测试与验收

- share policy、usage ingest idempotency、secret ref、mock console/stats/enterprise/function APIs。
