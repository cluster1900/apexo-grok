# Cloud Console、Stats 与 Enterprise接口设计

## 1. 接口形态

- Console account/API key/billing/workspace/share/docs proxy。
- Stats ingest/lake/server/app。
- Enterprise share routes。
- Function GitHub App/JWT/Worker API。
- SST infra resources。

## 2. 请求 / 响应 schema

- CloudAccount、UsageReport、SharedSessionView、DeploymentStage、CloudSecretRef。
- Usage fields include provider/model/tokens/cost/latency/trace/session。

## 3. 错误码

- CloudAuthRequired
- SharePolicyDenied
- UsageIngestConflict
- CloudServiceUnavailable
- SecretResolutionFailed

## 4. 兼容性

- 外部路径、operationId、CLI 参数、配置字段和事件名以调研附件与上游源码为基线，Rust 实现不得无迁移说明地改名。
- 新增字段必须显式版本化；删除字段必须先提供兼容层和 progress 记录。
- 所有外部输入进入 application 前必须 schema 校验；外部文本进入 prompt 前必须截断并包裹 `<untrusted_input>`。

## 5. 示例

- 成功：usage outbox replay 到 stats ingest，按 provider/model/session trace 生成 UsageReport。
- 失败：secret ref 缺失返回 SecretResolutionFailed；重复 usage event 返回 UsageIngestConflict 或幂等成功。

## 6. Cloud Product Contract — 2026-05-27

- Console: route/action catalog, account/workspace/API key/billing/usage/share/docs proxy, Stripe/Honeycomb/webhook adapters.
- Function: Worker API for share/GitHub token/Feishu endpoints and GitHub App JWT.
- Stats: Firehose ingest, provider/model/geo aggregation, lake/Athena/MySQL/Drizzle schema boundary.
- Enterprise: share snapshot, compaction, storage adapter, Cloudflare build target.
- SST: console/enterprise/lake/monitoring/secret/stats/stage resources and secret names.
