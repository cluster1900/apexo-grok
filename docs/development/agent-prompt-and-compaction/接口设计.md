# Agent、Prompt 与 Compaction接口设计

## 1. 接口形态

- 配置接口: 内置 agent、custom agent、repo-local .opencode/agent/*.md。
- Prompt 资产接口: prompts/<scope>.<kind>.<version>.md 路径和版本引用。
- Session 接口: prompt 前解析 agent profile、summary/title/compaction 作为内部用例。

## 2. 请求 / 响应 schema

- AgentProfile: id、mode、model tier、tool allowlist、permission policy、prompt refs。
- CompactionPolicy: max context、reserved tokens、tail turns、summary model。
- PromptTemplateRef: path、version、hash、scope。

## 3. 错误码

- AgentNotFound=404
- PromptAssetInvalid=400
- ContextBudgetExceeded=409
- SummaryFailed=provider error
- SubagentPermissionDenied=403

## 4. 兼容性

- 外部路径、operationId、CLI 参数、配置字段和事件名以调研附件与上游源码为基线，Rust 实现不得无迁移说明地改名。
- 新增字段必须显式版本化；删除字段必须先提供兼容层和 progress 记录。
- 所有外部输入进入 application 前必须 schema 校验；外部文本进入 prompt 前必须截断并包裹 `<untrusted_input>`。

## 5. 示例

- 成功：加载 .opencode/agent/reviewer.md 后创建 AgentProfile，并在 prompt 前引用 prompts/session.system.<version>.md。
- 失败：agent prompt frontmatter 不合法返回 PromptAssetInvalid=400；subagent 越权返回 SubagentPermissionDenied=403。
