# Storage、Sync 与 Share接口设计

## 1. 接口形态

- SQLite repository API。
- Sync start/replay/history/steal endpoints。
- Share create/sync/remove and session share HTTP/SDK。
- Desktop migration progress event。

## 2. 请求 / 响应 schema

- SQLite tables from storage-schema inventory。
- SyncEvent: aggregate_id、seq、type、data、schema_version。
- SharedSession: share id、secret ref/url、policy、remote state。

## 3. 错误码

- MigrationFailed=500
- SchemaDrift=500
- SyncSequenceConflict=409
- SharePolicyDenied=403
- RemoteShareFailed=502
- StorageLocked=503

## 4. 兼容性

- 外部路径、operationId、CLI 参数、配置字段和事件名以调研附件与上游源码为基线，Rust 实现不得无迁移说明地改名。
- 新增字段必须显式版本化；删除字段必须先提供兼容层和 progress 记录。
- 所有外部输入进入 application 前必须 schema 校验；外部文本进入 prompt 前必须截断并包裹 `<untrusted_input>`。

## 5. 示例

- 成功：POST /sync/replay 写入 aggregate seq 后 projector 幂等更新 session/message projection。
- 失败：seq 不连续返回 SyncSequenceConflict=409；share policy disabled 时 session.share 返回 SharePolicyDenied=403。
