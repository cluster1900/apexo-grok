# LSP、PTY 与 IDE接口设计

## 1. 接口形态

- LSP diagnostics/symbols/hover/definition/references/status。
- PTY CRUD/connect-token/WebSocket write/resize/output/replay。
- IDE/editor context and formatter/image helpers。

## 2. 请求 / 响应 schema

- LspRange/Location/Diagnostic。
- PtyID/PtyTicket/PtyFrame/PtyCursor。
- IdeReference: file、range、selection text。

## 3. 错误码

- LspLaunchFailed=500
- LspUnsupportedLanguage=400
- PtyNotFound=404
- PtyTicketExpired=401
- PtyWriteFailed=500
- IdeContextInvalid=400

## 4. 兼容性

- 外部路径、operationId、CLI 参数、配置字段和事件名以调研附件与上游源码为基线，Rust 实现不得无迁移说明地改名。
- 新增字段必须显式版本化；删除字段必须先提供兼容层和 progress 记录。
- 所有外部输入进入 application 前必须 schema 校验；外部文本进入 prompt 前必须截断并包裹 `<untrusted_input>`。

## 5. 示例

- 成功：POST /pty 创建 session，POST /pty/{id}/connect-token 返回 ticket，WebSocket replay cursor 后开始输出。
- 失败：ticket 过期返回 PtyTicketExpired=401；LSP server 启动失败返回 LspLaunchFailed 并更新 lsp.status。

## 6. LSP / PTY / Terminal Contract — 2026-05-27

- LSP: lsp.status and find.symbols; tool lsp covers diagnostics、symbols、hover、definition、references. Server catalog and launch command derive from config/language mapping.
- PTY HTTP: pty.shells、pty.list、pty.create、pty.get、pty.update、pty.remove、pty.connectToken、pty.connect。
- PTY WebSocket: /pty/:ptyID/connect?directory&cursor&ticket/auth_token with x-opencode-ticket compatibility, cursor control frame, write/resize/output frames, reconnect/backoff, buffer serialization, clone recovery, workspace-scoped terminal cache.
- IDE: install/already-installed states, file/range selection, formatter catalog, image resize/data-url errors.
