# MCP、Plugin 与 Skill接口设计

## 1. 接口形态

- MCP JSON-RPC/StreamableHTTP/SSE/local stdio transport。
- MCP OAuth authorize/callback/authenticate。
- Plugin hooks/tools/providers/auth/TUI extension。
- Skill loader SKILL.md。

## 2. 请求 / 响应 schema

- MCPServerConnection: name、transport、status、auth、capabilities。
- PluginManifest: origin、permissions、hooks、provided tools/providers。
- SkillAsset: path、metadata、referenced files。

## 3. 错误码

- McpServerNotFound=404
- McpAuthRequired=401
- McpFrameInvalid=400
- PluginLoadFailed=500 isolated
- SkillInvalid=400

## 4. 兼容性

- 外部路径、operationId、CLI 参数、配置字段和事件名以调研附件与上游源码为基线，Rust 实现不得无迁移说明地改名。
- 新增字段必须显式版本化；删除字段必须先提供兼容层和 progress 记录。
- 所有外部输入进入 application 前必须 schema 校验；外部文本进入 prompt 前必须截断并包裹 `<untrusted_input>`。

## 5. 示例

- 成功：POST /mcp/{name}/auth/callback 完成 OAuth 后 mcp.status 显示 tools/resources/prompts。
- 失败：远程 MCP 不支持 OAuth 返回 UnsupportedOAuthError；plugin hook 抛错只隔离该 plugin，不中断 session。

## 6. MCP/Plugin Contract 下沉 — 2026-05-27

- MCP endpoints: mcp.status、mcp.add、mcp.auth.start、mcp.auth.callback、mcp.auth.authenticate、mcp.auth.remove、mcp.connect、mcp.disconnect。
- MCP status union includes connecting/connected/disconnected/error/auth-needed with tools/resources/prompts metadata.
- OAuth requires callback server, token store, client metadata and unsupported OAuth error mapping.
- Transport must support local stdio, remote StreamableHTTP and SSE fallback.
- Plugin loader covers file/npm sources, install/patch config, v1 plugin compatibility, themes, TUI plugin, workspace adapter, auth override and built-in auth/provider plugins.
- Skill loader checks name mismatch, referenced files and repo-local path safety.
