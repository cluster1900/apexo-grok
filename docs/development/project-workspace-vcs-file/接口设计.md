# Project、Workspace、VCS 与 File接口设计

## 1. 接口形态

- HTTP/SDK project/workspace/file/find/status endpoints。
- Workspace routing: query/header/directory/workspace。
- VCS: status/diff/apply/raw/worktree。

## 2. 请求 / 响应 schema

- ProjectID/WorkspaceID/WorkspaceRoot/ProjectPath newtype。
- FileContent: raw/patch/binary/image metadata。
- VcsPatch: files、hunks、cleanliness precondition。

## 3. 错误码

- ProjectNotFound=404
- WorkspaceViolation=403
- FileNotFound=404
- BinaryUnsupported=415
- VcsNotClean=409
- VcsApplyFailed=400

## 4. 兼容性

- 外部路径、operationId、CLI 参数、配置字段和事件名以调研附件与上游源码为基线，Rust 实现不得无迁移说明地改名。
- 新增字段必须显式版本化；删除字段必须先提供兼容层和 progress 记录。
- 所有外部输入进入 application 前必须 schema 校验；外部文本进入 prompt 前必须截断并包裹 `<untrusted_input>`。

## 5. 示例

- 成功：GET /file/content?path=src/main.rs 返回 File.Content，随后 file.watcher.updated 推送变更路径。
- 失败：../ 越界路径返回 WorkspaceViolation=403；vcs.apply 在 dirty worktree 返回 VcsNotClean=409。

## 6. Project/File/Workspace Contract — 2026-05-27

- Project endpoints: project.list、project.current、project.initGit、project.update。
- Workspace endpoints: experimental.workspace.adapter.list、experimental.workspace.list、experimental.workspace.create、experimental.workspace.syncList、experimental.workspace.status、experimental.workspace.remove、experimental.workspace.warp。
- Worktree endpoints: worktree.list、worktree.create、worktree.remove、worktree.reset。
- VCS endpoints: vcs.get、vcs.status、vcs.diff、vcs.diff.raw、vcs.apply。
- File endpoints: file.list、file.read、file.status、find.files、find.text、find.symbols。
- UI file tree contract must expose File.Node fields needed by allowed/modified filtering, drag data, watcher refresh, file view scroll/selection cache, diff status/additions/deletions/patch/before/after. file.watcher.updated is the canonical watcher event.
