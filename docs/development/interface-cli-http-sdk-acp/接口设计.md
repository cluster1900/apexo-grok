# CLI、HTTP、SDK 与 ACP接口设计

## 1. 接口形态

- CLI 33 command modules including default TUI/run/serve/web/acp/provider/mcp/session/github/plugin/db/debug。
- HTTP/SSE/WS 131 source endpoints and OpenAPI 131 operations。
- JS SDK generated v2。
- ACP and ACP-next stdio/frame protocol。

## 2. 请求 / 响应 schema

- CliInvocation: command、flags、cwd、env、format。
- HttpOperation: method/path/params/query/body/success/error。
- AcpRequest/AcpEvent/AcpToolCall。

## 3. 错误码

- CliUsageError
- BadRequest=400
- Unauthorized=401
- NotFound=404
- Conflict=409
- Internal=500 redacted
- AcpFrameInvalid

## 4. 兼容性

- 外部路径、operationId、CLI 参数、配置字段和事件名以调研附件与上游源码为基线，Rust 实现不得无迁移说明地改名。
- 新增字段必须显式版本化；删除字段必须先提供兼容层和 progress 记录。
- 所有外部输入进入 application 前必须 schema 校验；外部文本进入 prompt 前必须截断并包裹 `<untrusted_input>`。

## 5. 示例

- 成功：opencode run --format json 连接 mock provider，输出 session/message/tool event JSON；SDK session.create/prompt/messages 与 OpenAPI operationId 一致。
- 失败：Basic Auth 错误返回 401；HTTP schema error body 截断 invalid actual，不回显超大 payload。

## 6. Contract 下沉 — 2026-05-27

### HTTP groups and ownership

| 分组 | 数量/范围 | 功能目录 |
|---|---|---|
| config/control/global/instance | config、auth set/remove、health、path、dispose、upgrade、VCS | configuration、account、deployment、project |
| session/question/permission | session/message/part/prompt_async/revert/question/permission | session、tool |
| file/project/workspace/sync | file/find/symbol/status、project、workspace、sync replay/history | project、storage |
| provider/mcp/pty/tui/event | provider auth/catalog、MCP OAuth、PTY WS、TUI control、SSE | provider、mcp、lsp-pty、desktop |
| experimental | console/worktree/session/resource/tool/workspace | cloud、project、tool、mcp |

HTTP source endpoint 数量为 131；OpenAPI 生成物为 113 paths、131 operations、290 component schemas。Rust 实现必须同时 diff source inventory 和 OpenAPI inventory。

### CLI command coverage

33 个 command module 必须保留：account、acp、agent、db、debug/*（含 `scrap`、`startup`）、export、generate、github、import、mcp、models、plugin、pr、providers、run、serve、session、stats、attach/default TUI、uninstall、upgrade、web；`cmd.ts`、`prompt-display.ts` 为 CLI 支撑模块，不算独立命令但必须测试。

### Server middleware contract

必须覆盖 Basic Auth、CORS/Vary、compression、schema-error body cap、workspace routing、raw route auth、UI fallback、mDNS、proxy util、global/instance lifecycle、SDK v1 smoke 和 SDK error shape。
