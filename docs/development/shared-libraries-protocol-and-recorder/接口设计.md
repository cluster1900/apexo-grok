# 共享库、协议内核与 Recorder接口设计

## 1. 接口形态

- packages/core schemas/hooks exports。
- packages/llm providers/protocols/route/tool-runtime exports。
- http-recorder cassette/matching/redaction/websocket。
- script/codegen/spec parity。

## 2. 请求 / 响应 schema

- SharedSchema branded ids/typed errors。
- ProtocolFrame for OpenAI/Anthropic/Gemini/Bedrock。
- RecordedExchange cassette schema。

## 3. 错误码

- SchemaDrift
- ProtocolFrameInvalid
- RecordingMismatch
- RedactionViolation
- CodegenFailed

## 4. 兼容性

- 外部路径、operationId、CLI 参数、配置字段和事件名以调研附件与上游源码为基线，Rust 实现不得无迁移说明地改名。
- 新增字段必须显式版本化；删除字段必须先提供兼容层和 progress 记录。
- 所有外部输入进入 application 前必须 schema 校验；外部文本进入 prompt 前必须截断并包裹 `<untrusted_input>`。

## 5. 示例

- 成功：OpenAI Responses stream 经 ProtocolAdapter 转为 text/tool/usage frames，并写入 redacted cassette。
- 失败：cassette 含 Authorization header 明文触发 RedactionViolation；Rust schema 与 specs/v2/session.md 不一致触发 SchemaDrift。

## 6. Specs/Protocol Contract — 2026-05-27

- specs/project.md owns multi-project/worktree API shape and must be compared with project/workspace HTTP groups.
- specs/v2/provider-model.md owns provider/model v2 schema and must be compared with packages/core and packages/llm provider catalog.
- specs/v2/session.md owns session/message v2 model and must be compared with MessageV2 and Rust serde schema.
- packages/http-recorder cassette schema covers request matching, redaction, response replay and websocket frames.
