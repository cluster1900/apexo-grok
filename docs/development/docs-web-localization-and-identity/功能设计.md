# Docs/Web、本地化与 Identity 资产开发设计

## 1. 目标与非目标

- 目标：保留 docs site、marketing/share page、README locales、glossary、identity logo/icon 资产和 docs update/sync workflow。
- 非目标：把静态内容全部迁入 Rust binary。

## 2. 背景

上游入口：`packages/docs/*`、`packages/web/*`、`README.*.md`、`.opencode/glossary/*`、`packages/identity/*`。

## 3. 领域模型

| 对象 | 说明 |
|---|---|
| `DocsPage` | docs/quickstart/settings/AI tools/snippets。 |
| `LocaleAsset` | README locale、glossary、app/ui i18n key。 |
| `IdentityAsset` | mark/logo/icon 及 light/dark/size variant。 |
| `ShareWebPage` | web/enterprise share page contract。 |

## 4. 用例编排

- docs content update -> locale/glossary sync -> build/deploy docs/web。
- identity asset update -> desktop/app/web/extension package verify。
- share page -> consume public share contract -> render without secret leakage。

## 5. 关键边界

- `DocsBuildPort`、`LocaleSyncPort`、`IdentityAssetRegistry`、`SharePageContract`。

## 6. 错误模型

`DocsBuildFailed`、`LocaleKeyMissing`、`IdentityAssetMissing`、`SharePageSchemaDrift`。

## 7. 测试与验收

- docs locale sync、web build, identity asset presence, share page contract, screenshot smoke。
