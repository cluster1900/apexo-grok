# Docs/Web、本地化与 Identity 资产接口设计

## 1. 接口形态

- packages/docs content and docs.json。
- packages/web Astro pages/share/marketing。
- README locale and .opencode/glossary。
- identity logos/icons。

## 2. 请求 / 响应 schema

- DocsPage: route、title、content、assets。
- LocaleAsset: locale、keys、source。
- IdentityAsset: variant、size、theme、path。
- SharePageContract。

## 3. 错误码

- DocsBuildFailed
- LocaleKeyMissing
- IdentityAssetMissing
- SharePageSchemaDrift

## 4. 兼容性

- 外部路径、operationId、CLI 参数、配置字段和事件名以调研附件与上游源码为基线，Rust 实现不得无迁移说明地改名。
- 新增字段必须显式版本化；删除字段必须先提供兼容层和 progress 记录。
- 所有外部输入进入 application 前必须 schema 校验；外部文本进入 prompt 前必须截断并包裹 `<untrusted_input>`。

## 5. 示例

- 成功：docs.json navigation 构建 quickstart/settings 页面，identity light/dark logo 都在产物中。
- 失败：app/ui locale key 缺失返回 LocaleKeyMissing；share page schema drift 阻塞 docs/web 构建。

## 6. Locale/Identity Contract — 2026-05-27

- Locale matrix must distinguish README locales, .opencode/glossary/*, packages/app/src/i18n/*, packages/ui/src/i18n/*, desktop renderer/loading strings and packages/web localized content.
- packages/docs/docs.json drives docs navigation; quickstart/settings/AI tools/snippets/images/logo must be covered by docs build tests.
- Identity assets include light/dark SVG, 96/192/512 PNG and desktop/extension/web variants; missing variant is a packaging failure.
