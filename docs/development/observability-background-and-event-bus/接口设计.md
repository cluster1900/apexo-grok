# 可观测、Background 与事件总线接口设计

## 1. 接口形态

- Domain event envelope。
- Bus publish/subscribe。
- SSE global/session event bridge。
- Background job runner。
- Trace/log/metrics fields。

## 2. 请求 / 响应 schema

- EventEnvelope: schema_version、trace_id、aggregate_id、occurred_at、payload。
- BackgroundJob: id、kind、status、cancellation、result。

## 3. 错误码

- EventSchemaInvalid
- ProjectorFailed
- JobCancelled
- JobTimeout
- TraceContextMissing

## 4. 兼容性

- 外部路径、operationId、CLI 参数、配置字段和事件名以调研附件与上游源码为基线，Rust 实现不得无迁移说明地改名。
- 新增字段必须显式版本化；删除字段必须先提供兼容层和 progress 记录。
- 所有外部输入进入 application 前必须 schema 校验；外部文本进入 prompt 前必须截断并包裹 `<untrusted_input>`。

## 5. 示例

- 成功：session.updated domain event 带 trace_id/schema_version/aggregate_id，projector 幂等更新后 SSE 推送。
- 失败：projector 失败记录 ProjectorFailed span 并可重试；background job timeout 发布 JobTimeout。
