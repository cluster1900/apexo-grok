# 按功能开发拆分索引

## 1. 定位

`opencode-rust-webjs-port` 是迁移总方案，只维护跨功能的目标、阶段、兼容原则和全局风险。具体开发不得继续集中写在本目录；后续按下表进入对应功能目录。

## 3. 使用规则

- 实现一个功能时，先更新对应目录的 `功能设计.md`，并补 `接口设计.md`、`数据设计.md`、`测试矩阵.md` 中适用的文件。
- 触碰多个功能时，每个功能目录都要记录影响面；总方案只记录跨功能取舍。
- `progress/` 和 `testing/` 后续新增子目录时必须与本表功能目录同名。
