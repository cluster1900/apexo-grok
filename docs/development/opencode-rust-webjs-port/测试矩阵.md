## 2. 场景测试

- 新建 session -> prompt -> provider mock streaming -> tool call -> permission approve -> message complete。
- `prompt_async` 返回后后台完成并通过 SSE 更新 UI。
- `run --format json` 输出事件序列。
- MCP remote OAuth start/callback/connect/list tools。
- PTY create/connect-token/websocket/write/replay/remove。
- Desktop sidecar start -> migration progress -> health ready -> renderer SDK call。
- GitHub Action issue/PR/review comment -> session prompt -> branch/PR/comment/share with mocked GitHub API。
- VS Code command with active selection -> `@File#Lx-y` reference inserted into opencode terminal。
- `.opencode` custom command/agent/tool/theme loaded under workspace guard and denied when path escapes。
- Installer with linux-musl/x64-baseline/darwin-arm64 target selects expected artifact。
- Provider request replayed from cassette with auth/header/body redaction assertions。

## 6. 对抗性测试

- Workspace path traversal、symlink escape、non-git `worktree="/"`。
- Prompt injection in file/tool/web/MCP output with `<untrusted_input>` assertion。
- Secret leakage in logs/prompt/command line。
- Dangerous shell/patch operations requiring explicit approval。
- Untrusted plugin/MCP server requesting elevated permission。
- Malicious GitHub/Slack/editor input attempting prompt injection or secret exfiltration。
- Malicious `.opencode` custom tool/theme/plugin escaping workspace or requesting elevated permission。
- Installer/release path traversal, checksum mismatch, and compromised artifact metadata。

## 7. Prompt 回归

- System prompt version snapshot。
- Agent prompt build/build-switch/plan/compaction/title/summary regression。
- Tool description snapshot per model/provider。
- Repo-local agent/command/skill prompt asset snapshot and locale/glossary regression。

## 8. Agent Eval

- Trajectory：文件修改、测试运行、错误恢复。
- Tool-use accuracy：read/grep/edit/apply_patch/bash/mcp/task。
- LLM-as-judge：final answer groundedness and safety。
- Cost-latency：首 token、tool roundtrip、total tokens。
- Baseline：与上游 opencode 同 prompt 输出行为比较。
- Productization：GitHub Action、VS Code、install、Nix、cloud share/stats 的 contract baseline。
