# opencode Rust + WebJS desktop 迁移功能设计

> 本目录是迁移总方案，不再作为唯一功能开发目录。具体功能开发入口见 [功能拆分索引](功能拆分索引.md)，后续实现必须按功能目录分别维护设计、接口、数据和测试文档。

## 1. 目标与非目标

### 目标

- 完整迁移 `/Users/hawk_wu/Desktop/opencode` 的 agent core 到 Rust，并保留 WebJS desktop。
- 保持 CLI、HTTP/SSE/WS、JS SDK、Tool、Desktop preload/sidecar 的入参/出参兼容。
- 使用 DDD 分层实现核心业务：domain/application/infrastructure/interface。
- 覆盖 session、agent、tool、provider/model、config、permission、mcp、plugin、project/workspace、storage/sync/share、lsp、pty、file、desktop/web、tui、sdk、外围集成。
- 覆盖 root 级产品化能力：install、Nix、CI/CD、release scripts、containers、dependency patches、infra/SST、docs/identity assets、`.opencode` repo-local prompt/config 资产、`packages/core`/`packages/llm`/`http-recorder` 共享库。
- 对开发/架构文档做源码完整性验证，并记录子 agent 核对结果。

### 非目标

- 本阶段不直接写 Rust 代码。
- 本阶段不重新设计产品交互，不删除上游已有功能。
- 本阶段不决定所有 provider Rust crate 选型；crate 引入需另做 research。
- 本阶段不承诺 TUI 一次性 Rust 重写，TUI 可通过兼容接口分阶段迁移。

## 4. 用例编排

| 用例 | 步骤 |
|---|---|
| 发送 prompt | interface 解析请求 -> application 加载 session/agent/config/model -> domain 创建 user message -> provider streaming -> processor 更新 assistant message/part -> tool call 经 permission/tool registry -> 事件/SSE 推送 -> repository 持久化。 |
| 异步 prompt | 写入 user message -> 注册 runner -> 立即返回 `204` -> 后台 processor 推送事件。 |
| 执行 tool | processor 校验 tool args -> permission workflow -> infrastructure adapter 执行 -> output truncator -> part completed/error -> session updated。 |
| Provider OAuth | CLI/HTTP 发起 authorize -> provider auth service 生成 URL/method -> callback 校验 state/code -> auth repository 写 secret ref。 |
| MCP OAuth/connect | config/add server -> connector 选择 local/remote transport -> OAuth start/callback/authenticate -> tools/resources/prompts 更新。 |
| PTY attach | create pty -> connect-token 生成短期 ticket -> WebSocket 校验 ticket -> replay cursor/buffer -> stream write/resize/output。 |
| Desktop 启动 | Electron main 设置 env/proxy/cert -> utility sidecar start -> Rust server listen -> SQLite migration progress -> `/global/health` -> renderer 初始化 SDK。 |
| Sync replay | 接收 event history -> domain 校验 aggregate/seq/version -> projector 幂等写库 -> 返回 replay/history。 |
| Share/unshare | 校验 config/env share policy -> create/remove remote share -> 保存/清理 `session_share` -> session updated。 |
| GitHub Action 触发 | webhook/comment event -> 解析 `/opencode`/`/oc` -> 校验 actor 权限 -> resolve issue/PR/diff context -> session prompt -> branch/commit/PR/share/reply。 |
| Editor extension 调用 | VS Code/Zed command -> 读取 selection/file reference -> CLI/HTTP/SDK append prompt -> TUI/terminal focus 或新 session。 |
| Repo-local asset 加载 | workspace guard -> 读取 `.opencode` agent/command/skill/tool/theme -> schema 校验 -> 注册到 session/tool/plugin/TUI adapter。 |
| 发布安装 | 选择 release artifact -> platform target 探测 -> checksum/signature 校验 -> 安装/更新 PATH -> 记录 version/rollback。 |
| Provider 录制回放 | provider request -> recorder 匹配/录制 cassette -> secret redaction -> replay streaming/tool frame -> golden assertion。 |

## 6. 错误模型

- 业务可预期失败：`DomainError::{NotFound, Busy, PermissionDenied, WorkspaceViolation, InvalidState, InvalidInput}`。
- 基础设施失败：`InfrastructureError::{Storage, Provider, Process, Network, Mcp, Plugin, Pty, Lsp}`。
- Interface 映射：400 schema/input，401 auth，404 not found，409 busy/conflict，500 脱敏 internal。
- Provider/API 错误保留 retryable/statusCode/header/body 摘要，body 脱敏和长度限制。

## 8. 回滚方案

- M1/M2 保留上游 TS server 可运行路径；Rust sidecar 用 feature flag 控制。
- WebJS SDK base URL 可切回 TS sidecar。
- SQLite schema 变更必须带 rollback migration；只读兼容阶段不写破坏性迁移。
- Provider/tool 高风险路径默认灰度，失败时降级到 TS adapter 或禁用 feature。

## 9. Agent 类附加设计

| 项 | 规划 |
|---|---|
| 模型档位选择 | primary 默认 `standard`，summary/title/compaction 可用 `cheap/small_model`，复杂代码修改可选 `strong`。 |
| Tool 设计 | 以 [Tool 清单](../../research/opencode-upstream-analysis/附件/tool-inventory.generated.md) 为基线；每个 tool 定义 `name/description/input_schema/permission_level/idempotent/timeout/output_schema`。 |
| Prompt 设计 | prompt 资产迁移到 `prompts/<scope>.<kind>.<version>.md`；外部内容 `<untrusted_input>` 包裹。 |
| 审批/权限 | `read/write/execute/network/dangerous`；shell、write/edit/apply_patch、mcp/plugin 默认触发审批。 |
| 停止条件 | max iterations、token/cost budget、用户中断、provider timeout、tool timeout、doom loop。 |
| 可观测 | `trace_id/session_id/message_id/tool.name/gen_ai.*`。 |
| Eval 设计 | trajectory、tool-use accuracy、LLM-as-judge、cost-latency budget、上游基线回归。 |
