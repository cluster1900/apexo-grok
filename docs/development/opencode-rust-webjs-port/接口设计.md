# opencode Rust + WebJS desktop 迁移接口设计

## 1. 接口形态

| 形态 | 规划基线 | 说明 |
|---|---|---|
| CLI/TUI | [CLI 命令清单](../../research/opencode-upstream-analysis/附件/cli-command-inventory.generated.md) | 保持 command 字符串、参数、输出模式和默认 TUI 行为。 |
| HTTP | [HTTP API 清单](../../research/opencode-upstream-analysis/附件/http-api-inventory.generated.md) + [OpenAPI Schema 清单](../../research/opencode-upstream-analysis/附件/openapi-schema-inventory.generated.md) | 保持 operationId、path、method、params/query/payload/success/error 和字段级 schema/ref。 |
| SSE | `/event`、`/global/event` | `text/event-stream`，推送 session/message/part/permission/pty/lsp/project/mcp/global 事件。 |
| WebSocket | `/pty/:ptyID/connect?ticket=...` | PTY 文本流和 cursor 控制帧。 |
| Tool 协议 | [Tool 清单](../../research/opencode-upstream-analysis/附件/tool-inventory.generated.md) | Provider tool schema、permission、execution result。 |
| Desktop preload | `packages/desktop/src/preload/types.ts` | WebJS renderer 的 native 能力白名单。 |
| Sidecar IPC | `packages/desktop/src/main/server.ts`、`sidecar.ts` | Electron main 与 Rust server sidecar 的启动/停止/ready/error/migration progress。 |
| JS SDK | `packages/sdk/js/src/v2/gen/*` | Rust OpenAPI 生成兼容 SDK。 |
| GitHub Action | `github/action.yml`、`github/index.ts` | issue/PR/review comment 触发、diff context、branch/PR/share/reply。 |
| Editor extensions | `sdks/vscode/package.json`、`sdks/vscode/src/extension.ts`、`packages/extensions/zed/*` | VS Code/Zed command、keybinding、terminal/CLI/SDK 调用、file reference。 |
| Cloud/hosted API | `packages/console/*`、`packages/stats/*`、`packages/enterprise/*`、`packages/function/*` | account/API key/billing/usage/share/stats/function contract。 |
| Installer/release | `install`、`flake.nix`、`nix/*`、`.github/workflows/*`、`packages/containers/*` | 平台 target、artifact、CI container、Nix derivation、release/publish workflow。 |
| Repo-local assets | `.opencode/*` | agent/command/skill/tool/theme/glossary/TUI 配置加载 contract。 |

## 2. 请求 / 响应 schema

### HTTP

HTTP 入参/出参以 `http-api-inventory.generated.md` 和 `openapi-schema-inventory.generated.md` 为规划主表。每行含：

- `params`：path 参数，例如 `sessionID`、`messageID`、`partID`、`providerID`、`ptyID`、`requestID`。
- `query`：workspace routing、分页、搜索、filter、cursor 等 query。
- `payload`：JSON body 或 no content。
- `success`：Effect/OpenAPI Schema 名称，对应 Rust response type。
- `error`：HTTP/业务错误 schema。
- `path params/query/request body/success responses/error responses`：OpenAPI 字段级 schema/ref。

实现阶段必须为每个 operationId 生成 Rust handler 测试，断言 OpenAPI JSON 中 method/path/request/response 与规划清单一致。

### CLI

CLI 入参以 `cli-command-inventory.generated.md` 为规划主表。输出分类：

| 命令 | 输出 |
|---|---|
| 默认 TUI、`attach` | TUI 进程/终端 UI。 |
| `run --format default` | 格式化 stream。 |
| `run --format json` | raw JSON events。 |
| `session list --format table/json` | 表格或 JSON。 |
| `export` | session JSON，可 `--sanitize`。 |
| `db [query] --format json/tsv` | 查询结果。 |
| `serve/web/acp` | server URL、Web UI 或 ACP stdio protocol。 |

### Tool

Tool 入参以 `tool-inventory.generated.md` 为规划主表。统一响应：

| 字段 | 类型 | 说明 |
|---|---|---|
| `title` | string | UI 展示标题。 |
| `output` | string | 模型可见输出，可能已截断。 |
| `metadata` | object | tool 特定 metadata，含 `truncated/outputPath`。 |
| `attachments` | array | 可选 file/image/pdf 等附件。 |

### Desktop preload

| API | 入参 | 出参 |
|---|---|---|
| `awaitInitialization(onStep)` | callback(`InitStep`) | `{url, username, password}` |
| `openDirectoryPicker(opts?)` | `{multiple,title,defaultPath}` | `string|string[]|null` |
| `openFilePicker(opts?)` | `{multiple,title,defaultPath,accept,extensions}` | `string|string[]|null` |
| `saveFilePicker(opts?)` | `{title,defaultPath}` | `string|null` |
| `readClipboardImage()` | 无 | `{buffer,width,height}|null` |
| `checkUpdate()` | 无 | `{updateAvailable,version?}` |
| `storeGet/Set/Delete/Clear/Keys/Length` | store name/key/value | string/null、void、keys、length |

完整 API 以 `packages/desktop/src/preload/types.ts` 为准，Rust 迁移不得缩减。

### External integrations

| 集成 | 入参 | 出参 / 副作用 |
|---|---|---|
| GitHub Action | GitHub event、`/opencode`/`/oc` comment、workflow inputs/env、optional mock event | session run、branch/commit/PR、issue/PR comment、share URL、artifact/log。 |
| VS Code | command/keybinding、active editor selection、file path/range | 复用或新建 opencode terminal，插入 `@File#Lx-y` 引用。 |
| Zed | extension manifest、command/icon、sync workflow | 调用 CLI/SDK 的编辑器入口，保持 manifest 可发布。 |
| Slack/ACP | platform event 或 ACP stdio request | 转为已校验 session prompt/tool intent，回复外部平台。 |

### Deployment and assets

| 接口 | 入参 | 出参 / 副作用 |
|---|---|---|
| Installer | version、binary path、no-modify-path、platform facts | 安装 binary、可选修改 shell PATH、输出版本/错误。 |
| Nix | system、overlay、hash | `opencode`、`opencode-desktop` derivation。 |
| CI containers | image name、tag、push flag | base/bun-node/rust/tauri-linux/publish image。 |
| Repo-local asset loader | workspace root、`.opencode` 文件 | validated agent/command/skill/tool/theme/glossary registry。 |
| HTTP recorder | request/response/WS frame、redaction policy | cassette、replay result、redaction assertion。 |

## 3. 错误码

| 错误 | HTTP | CLI 展示 | 触发 |
|---|---:|---|---|
| `BadRequest` | 400 | schema/path/query/payload 错误 | 入参校验失败。 |
| `Unauthorized` | 401 | auth failed | Basic Auth 失败。 |
| `NotFound` | 404 | not found | session/project/provider/mcp/pty/question/permission 不存在。 |
| `Conflict`/`SessionBusy` | 409 | session busy | session 已有 runner。 |
| `PermissionDenied` | 403/200 tool error | denied | 用户/规则拒绝工具。 |
| `ProviderAuthError` | 400 | provider auth failed | 缺 credential/OAuth 失败。 |
| `McpServerNotFound` | 404 | MCP not found | MCP name 不存在。 |
| `VcsApplyError` | 400 | non-git/not-clean | patch 不能应用。 |
| `Internal` | 500 | redacted internal error | 未分类基础设施错误。 |

## 4. 兼容性

- OpenAPI operationId、path、method 不改名。
- 保留 deprecated `permission.respond` 直到 JS SDK 和 UI 全部切换到 `permission.reply`。
- 保留 `autoshare`、`mode`、`tools` 等旧配置的迁移兼容。
- 保留 `directory/workspace` query 与 `x-opencode-directory/x-opencode-workspace` header 双路径。
- 保留 `/api/*` v2 public API 与 legacy experimental API。
- 保留 GitHub Action、VS Code、Zed、Slack/ACP 等外部消费者只通过 CLI/HTTP/SDK contract 进入 core。
- 保留 install/Nix/container/release workflow 的平台 target 和 artifact 命名语义。
- 保留 `.opencode` repo-local agent/command/skill/tool/theme/glossary 的加载能力，但所有自定义 tool/plugin 默认不受信。

## 5. 示例

成功：

```http
POST /session/{sessionID}/message?directory=/repo
Content-Type: application/json

{"parts":[{"type":"text","text":"run tests"}],"providerID":"openai","modelID":"gpt-5"}
```

响应：

```json
{"info":{"id":"msg...","role":"assistant"},"parts":[]}
```

失败：

```json
{
  "name": "SessionBusyError",
  "data": {"sessionID": "ses..."}
}
```
