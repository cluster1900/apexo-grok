# 配置与 Repo-local 资产接口设计

## 1. 接口形态

- Config file JSONC、OPENCODE_* env、CLI flags。
- .opencode/opencode.jsonc、tui.json、agent/command/skills/tool/themes/glossary。
- Settings UI/HTTP config endpoint。

## 2. 请求 / 响应 schema

- ResolvedConfig: provider/mcp/lsp/formatter/permission/tool/layout/server/share。
- RepoLocalAsset: type、name、path、hash、schema_version。
- Secret 字段只允许 env/secret ref。

## 3. 错误码

- ConfigParseError=400 with path/line
- ConfigSchemaError=400 field path
- SecretInConfig=400
- AssetPathViolation=403
- RepoAssetInvalid=400

## 4. 兼容性

- 外部路径、operationId、CLI 参数、配置字段和事件名以调研附件与上游源码为基线，Rust 实现不得无迁移说明地改名。
- 新增字段必须显式版本化；删除字段必须先提供兼容层和 progress 记录。
- 所有外部输入进入 application 前必须 schema 校验；外部文本进入 prompt 前必须截断并包裹 `<untrusted_input>`。

## 5. 示例

- 成功：PATCH /config 更新 formatter/lsp/mcp 字段后返回完整 Config.Info，并触发受影响服务 reload。
- 失败：配置文件含 API key 明文字段返回 SecretInConfig=400；.opencode/tool 路径越界返回 AssetPathViolation=403。

## 6. Config.Info 字段基线 — 2026-05-27

必须在字段级覆盖：server、command、skills、reference、watcher、snapshot、plugin、share/legacy autoshare、enabled_providers、disabled_providers、agent/legacy mode、mcp、formatter、lsp、permission、attachment、tool_output、compaction、experimental。

加载入口包括 config files、managed plist、OPENCODE_CONFIG_CONTENT、Windows/Linux/macOS path resolution、repo-local .opencode assets、plugin spec dedupe、Markdown/frontmatter commands and agents.
