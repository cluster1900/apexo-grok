# Session 生命周期与消息接口设计

## 1. 接口形态

- HTTP/SDK: session create/list/get/update/delete/fork/children/archive/share/revert/compact/abort/prompt/prompt_async/message list/message detail/question answer。
- SSE: session.updated、message.updated、message.part.updated、message.part.delta、question.asked/question.replied/question.rejected。
- CLI/TUI: run、session 子命令、TUI prompt 与 permission/question 交互。

## 2. 请求 / 响应 schema

- SessionID/MessageID/PartID/QuestionID 使用 newtype，禁止裸 String 泄漏到 domain。
- Message part 支持 text、reasoning、file、tool、step、subtask、agent，状态为 pending/streaming/completed/error/aborted。
- Prompt request 包含 parts、provider/model、agent、directory/workspace、async、structured output schema。

## 3. 错误码

- SessionNotFound=404
- SessionBusy=409
- InvalidPartState=400
- QuestionExpired=409
- AbortRequested=200 event/error part
- StorageFailure=500 脱敏

## 4. 兼容性

- 外部路径、operationId、CLI 参数、配置字段和事件名以调研附件与上游源码为基线，Rust 实现不得无迁移说明地改名。
- 新增字段必须显式版本化；删除字段必须先提供兼容层和 progress 记录。
- 所有外部输入进入 application 前必须 schema 校验；外部文本进入 prompt 前必须截断并包裹 `<untrusted_input>`。

## 5. 示例

- 成功：POST /session/{sessionID}/message，payload 含 text/file parts、provider/model/agent，返回 MessageV2.WithParts 并通过 SSE 推送 message.part.updated。
- 失败：同一 session runner busy 时返回 SessionBusy=409；未知 sessionID 返回 SessionNotFound=404，错误体不得包含 prompt 原文。

## 6. 上游 Contract 下沉 — 2026-05-27

### Session / Question / Permission operations

| 组 | operationId | 路径/语义 | 归属 |
|---|---|---|---|
| session | session.list、session.status、session.get、session.children、session.todo、session.diff | session 列表、状态、详情、子会话、todo、diff | 本功能 |
| session | session.messages、session.message、session.deleteMessage、part.delete、part.update | message/part 查询和编辑 | 本功能 |
| session | session.create、session.delete、session.update、session.fork、session.abort、session.init | lifecycle mutation | 本功能 |
| session | session.prompt、session.prompt_async、session.command、session.shell | prompt/async/command/shell 入口 | 本功能 + Tool/Provider |
| session | session.revert、session.unrevert、session.summarize | revert/summary/compact 相关入口 | 本功能 + Agent Prompt |
| question | question.list、question.reply、question.reject | pending question 列表、回复、拒绝 | 本功能 |
| permission legacy | permission.respond | legacy session-scoped permission reply，兼容保留 | 本功能 + Tool Permission |

### Message part union

必须完整覆盖 text、reasoning、file、tool、step-start、step-finish、snapshot、patch、agent、retry、compaction、subtask。Rust enum 使用 serde tag type，字段名与 MessageV2.Part 保持兼容。

### Event names

- session/message: session.updated、session.deleted、session.status、message.updated、message.removed、message.part.updated、message.part.delta、message.part.removed。
- question: question.asked、question.replied、question.rejected。不得使用旧的 answered 事件名。
- permission: permission.asked、permission.replied。

### Async prompt and recovery

session.prompt_async 返回 204 NoContent 后必须通过 SSE/Global event 恢复状态；CLI run stream 需要在漏收 question.asked 时调用 question.list 恢复 pending question。wait/context 行为归入 runner state，不能只靠 HTTP request 生命周期表达。
