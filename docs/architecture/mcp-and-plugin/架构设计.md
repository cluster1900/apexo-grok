# MCP & Plugin 架构设计

## 1. 职责与边界

本上下文负责 MCP server lifecycle、本地/远程 transport、OAuth、resources/prompts/tools、plugin 加载、hook 触发、TUI plugin 扩展和 workspace adapter。它不直接决定 session prompt 或 provider model。

上游证据：`packages/opencode/src/mcp/`、`packages/opencode/src/plugin/`、`packages/plugin/src/`、`packages/opencode/src/cli/cmd/tui/plugin/`。

## 2. 核心概念

| 类型 | 名称 | 说明 |
|---|---|---|
| 聚合根 | `MCPServerConnection` | name、type、status、transport、oauth、tools/resources。 |
| 聚合根 | `PluginRuntime` | plugin module、hooks、tools、provider、TUI extensions、dispose。 |
| 值对象 | `MCPServerName`、`OAuthState` | MCP 身份和 OAuth 临时态。 |
| 值对象 | `PluginID`、`HookName` | 插件身份和 hook 名。 |
| 领域服务 | `MCPConnector` | connect/disconnect/authenticate/callback。 |
| 领域服务 | `PluginHookDispatcher` | 触发 hook 并隔离失败。 |

## 3. 模块拓扑

| 层 | 模块 |
|---|---|
| domain | `mcp/server.rs`、`mcp/oauth.rs`、`plugin/runtime.rs`、`plugin/hook.rs` |
| application | `connect_mcp.rs`、`add_mcp.rs`、`authenticate_mcp.rs`、`load_plugins.rs`、`dispatch_hook.rs` |
| infrastructure | `mcp_stdio.rs`、`mcp_streamable_http.rs`、`mcp_sse.rs`、`node_plugin_host.rs` |
| interface | `/mcp*`、`mcp` CLI、plugin SDK、TUI plugin API |

## 4. 对外契约

- HTTP：`mcp.status/add/auth.start/auth.callback/auth.authenticate/auth.remove/connect/disconnect`。
- CLI：`mcp add/list/auth/logout/debug`。
- Plugin SDK：hook、tool、provider、auth、permission、command、shell env、TUI slot/route/keymap/theme/KV/dialog/toast。

## 5. 关键不变量

- 外部 MCP/plugin 默认不受信，权限默认 ask。
- MCP remote 先尝试 StreamableHTTP，再 SSE；失败状态必须可观测。
- OAuth pending transport 不能泄漏 secret；callback state 必须匹配。
- plugin hook 失败不能破坏核心业务，除明确声明为 blocking hook。
- plugin dispose 必须在进程退出、reload、workspace 切换时执行。

## 6. 错误模型

| 错误 | 类型 | 场景 |
|---|---|---|
| `McpServerNotFound` | application | server name 不存在。 |
| `McpUnsupportedOAuth` | domain/application | server 不支持 OAuth。 |
| `McpConnectionFailed` | infrastructure | transport 建连失败。 |
| `PluginLoadFailed` | infrastructure | module import/manifest 失败。 |
| `PluginHookFailed` | infrastructure/application | hook 执行失败。 |

## 7. 扩展点

- 新 MCP transport 作为 infrastructure adapter，不影响 domain。
- 新 hook 必须登记输入/输出 schema 和是否 blocking。
- TUI plugin 能力通过 WebJS/Rust bridge 暴露，不直接访问 domain。
