# Desktop WebJS 架构设计

## 1. 职责与边界

本上下文负责 Electron/WebJS desktop shell、sidecar lifecycle、preload IPC、Web UI、native picker、clipboard、notification、deeplink、updater、logs、WSL path、window state。业务能力只通过本地 Rust server 暴露。

上游证据：`packages/desktop/src/main/`、`packages/desktop/src/preload/`、`packages/app/src/`。

## 2. 核心概念

| 类型 | 名称 | 说明 |
|---|---|---|
| 聚合根 | 无 | Desktop 是 interface/adapter，不拥有业务聚合。 |
| 值对象 | `SidecarEndpoint` | url、username、password。 |
| 值对象 | `InitStep` | `server_waiting/sqlite_waiting/done`。 |
| 值对象 | `DeepLink` | `opencode://` URL。 |
| Adapter | `DesktopPreloadApi` | renderer 可调用的安全 API。 |

## 3. 模块拓扑

| 层 | 模块 |
|---|---|
| domain | 无 |
| application | `DesktopSidecarSupervisor` 只编排启动/停止，不放业务规则。 |
| infrastructure | Electron main、utility process、store、updater、native dialog、clipboard、notification。 |
| interface | preload API、WebJS app、HTTP/SSE/WS SDK client。 |

## 4. 对外契约

Desktop preload API 以 `packages/desktop/src/preload/types.ts` 为基线，必须覆盖：

- 初始化：`awaitInitialization(onStep) -> {url, username, password}`、`killSidecar()`、`loadingWindowComplete()`。
- 配置/store：`getDefaultServerUrl/setDefaultServerUrl`、`getWslConfig/setWslConfig`、`storeGet/Set/Delete/Clear/Keys/Length`。
- native：directory/file/save picker、`openLink`、`openPath`、clipboard image、notification。
- window：focus/show/relaunch、zoom、pinch zoom、titlebar、menu action。
- updater/log：`runUpdater/checkUpdate/installUpdate/exportDebugLogs/recordFatalRendererError`。

Sidecar IPC：

- main -> sidecar：`{type:"start", hostname, port, password, userDataPath, needsMigration}`、`{type:"stop"}`。
- sidecar -> main：`{type:"sqlite", progress}`、`{type:"ready"}`、`{type:"stopped"}`、`{type:"error", error}`。

## 5. 关键不变量

- Desktop 不直接访问 domain/SQLite；只通过 sidecar HTTP/SSE/WS。
- sidecar password 随机生成并用于 Basic Auth。
- `/global/health` ready 后才进入主 UI。
- 退出、relaunch、SIGINT/SIGTERM 必须停止 sidecar，不留子进程。
- native picker/clipboard 只通过 preload 白名单暴露给 renderer。

## 6. 错误模型

| 错误 | 类型 | 场景 |
|---|---|---|
| `SidecarStartTimeout` | interface/infrastructure | 60s 未 ready。 |
| `SidecarExitedBeforeReady` | infrastructure | utility process 早退。 |
| `DesktopIpcInvalidPayload` | interface | preload/main 入参非法。 |
| `UpdaterFailed` | infrastructure | 更新失败。 |

## 7. 扩展点

- WebJS 可继续使用 Solid app 和 JS SDK；Rust 端保持 HTTP/SSE/WS 兼容。
- 新 native 能力必须先加 preload 类型，再加 main handler，禁止 renderer 直接调用 Node/Electron。

## 8. 未决问题

- Electron 保留还是迁移到 Tauri 需另开 research；本方案按用户要求保留 WebJS desktop。
