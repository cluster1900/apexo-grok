# Tool Execution 架构设计

## 1. 职责与边界

本上下文负责 tool 定义、schema 校验、权限请求、执行结果、输出截断、插件 tool 包装和 provider/model 动态过滤。不负责 session 持久化、provider 调用、HTTP 路由。

上游证据：`packages/opencode/src/tool/tool.ts`、`tool/registry.ts`、`tool/*.ts`。

## 2. 核心概念

| 类型 | 名称 | 说明 |
|---|---|---|
| 聚合根 | `ToolCall` | 一次 tool 调用，包含 call id、tool id、input、status、output metadata。 |
| 值对象 | `ToolID` | 内置或插件 tool id。 |
| 值对象 | `ToolInputSchema` | JSON Schema/serde schema，执行前必校验。 |
| 值对象 | `PermissionLevel` | `read/write/execute/network/dangerous`。 |
| 领域服务 | `ToolRegistry` | 汇总内置、插件、MCP tool，并按 agent/model/flag 过滤。 |
| 领域服务 | `ToolOutputTruncator` | 按 max lines/bytes 截断并写入外部存储。 |

## 3. 模块拓扑

| 层 | 模块 |
|---|---|
| domain | `tool/definition.rs`、`tool/call.rs`、`tool/schema.rs`、`permission_level.rs` |
| application | `execute_tool.rs`、`register_tool.rs`、`ask_permission.rs` |
| infrastructure | `shell_tool.rs`、`file_tools.rs`、`git_tools.rs`、`web_tools.rs`、`mcp_tool_adapter.rs`、`plugin_tool_adapter.rs` |
| interface | provider tool schema、HTTP `experimental.tool*`、SDK tool type |

## 4. 对外契约

内置 tool 入参/出参以 [Tool 清单](../../research/opencode-upstream-analysis/附件/tool-inventory.generated.md) 为规划基线。所有 tool 返回：

```rust
pub struct ToolExecuteResult {
    pub title: String,
    pub output: String,
    pub metadata: serde_json::Value,
    pub attachments: Vec<FileAttachment>,
}
```

## 5. 关键不变量

- Tool 参数必须在执行前通过 schema 校验；校验失败返回模型可读的 invalid arguments。
- shell 命令必须参数化构造，不能 shell 字符串拼接审批逻辑。
- file/write/edit/apply_patch 必须通过 workspace path 值对象校验。
- doom loop：连续三次同 tool 同参数触发 `doom_loop` permission。
- `apply_patch` 与 `edit/write` 依据 provider/model 互斥暴露，保持上游行为。

## 6. 错误模型

| 错误 | 类型 | 场景 |
|---|---|---|
| `InvalidToolArguments` | domain | input 不满足 schema。 |
| `PermissionDenied` | domain/application | 用户或规则拒绝。 |
| `ToolTimeout` | infrastructure | tool 超时。 |
| `WorkspaceViolation` | domain/application | 路径越界。 |
| `ToolExecutionFailed` | infrastructure | shell/git/http/mcp/plugin 执行失败。 |

## 7. 扩展点

- 插件 tool：JS SDK 兼容层接收 `{description,args,execute}`，转为 Rust registry entry。
- MCP tool：MCP connector 发现后转为 `ToolDefinition`，权限默认不高于 ask。
- 自定义本地 tool：保留 `{tool,tools}/*.{js,ts}` 兼容加载，但进程隔离。
