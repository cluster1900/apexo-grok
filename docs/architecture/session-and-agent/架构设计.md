# Session & Agent 架构设计

## 1. 职责与边界

本上下文负责会话、消息、消息 part、agent profile、prompt 组装、session processor、summary/compaction、todo、fork/revert/share 状态和 subagent 编排。不负责 provider HTTP、tool 具体 I/O、SQLite 细节、CLI/HTTP DTO。

上游证据：`packages/opencode/src/session/`、`packages/opencode/src/agent/`、`packages/opencode/src/server/routes/instance/httpapi/groups/session.ts`。

## 2. 核心概念

| 类型 | 名称 | 说明 |
|---|---|---|
| 聚合根 | `Session` | 维护 session info、parent/children、title、agent/model、成本、tokens、revert/share、archive 状态。 |
| 实体 | `Message` | user/assistant message，按 session 归属。 |
| 实体 | `Part` | text/reasoning/file/tool/step/subtask/agent 等消息片段。 |
| 值对象 | `SessionID`、`MessageID`、`PartID` | 使用 newtype，构造时校验前缀/格式。 |
| 值对象 | `AgentProfile` | mode、model、prompt、permission、tools、description。 |
| 领域服务 | `SessionProcessor` | 把 prompt、provider stream、tool call 转为 message/part 事件。 |
| 领域服务 | `CompactionPolicy` | 判断 overflow、选择保留 tail turns、生成 summary。 |

## 3. 模块拓扑

| 层 | 模块 |
|---|---|
| domain | `session/model.rs`、`message.rs`、`part.rs`、`agent.rs`、`compaction.rs`、`events.rs` |
| application | `prompt_session.rs`、`fork_session.rs`、`summarize_session.rs`、`revert_session.rs`、`run_subagent.rs` |
| infrastructure | `session_repository_sqlite.rs`、`prompt_template_loader.rs`、`provider_stream_adapter.rs` |
| interface | `/session*` HTTP、`run`/TUI/SDK session API |

## 4. 对外契约

- HTTP：`session.*`、`part.*`、deprecated `permission.respond`，详见 [HTTP 清单](../../research/opencode-upstream-analysis/附件/http-api-inventory.generated.md)。
- CLI：`run`、默认 TUI、`session list/delete`、`export/import`，详见 [CLI 清单](../../research/opencode-upstream-analysis/附件/cli-command-inventory.generated.md)。
- 事件：`session.created/updated/deleted/status`、`message.updated/removed`、`message.part.updated/delta`。

## 5. 关键不变量

- 一次事务只修改一个 `Session` 聚合；跨 session 的 child 删除通过 application 编排。
- `Part` 状态从 `pending/running` 结束时必须转 `completed/error`，中断不能留下 dangling tool call。
- 同一 session 同时只能有一个 active runner；`SessionBusyError` 是可预期业务失败。
- `revert` 必须引用存在的 message/part/snapshot。
- `Session.remove` 必须递归处理 child session，并取消关联后台任务。

## 6. 错误模型

| 错误 | 类型 | 场景 |
|---|---|---|
| `SessionNotFound` | domain/application | sessionID 不存在。 |
| `SessionBusy` | domain/application | prompt/shell/revert 时已有 runner。 |
| `InvalidMessagePart` | domain | part schema 或状态转移非法。 |
| `ProviderFailure` | infrastructure | provider stream/API 失败，映射到 assistant message error。 |
| `StorageFailure` | infrastructure | SQLite/迁移/锁失败。 |

## 7. 扩展点

- 新 agent profile 通过 config/plugin 注入，但必须转为 `AgentProfile` 值对象。
- 新 message part 类型必须注册 schema、事件和 SDK 类型。
- 新 prompt 模板必须放 `prompts/` 或等价资源文件，代码只引用路径和版本。

## 8. 未决问题

- 上游 prompt 文本的完整迁移需另开 Prompt 调研和回归报告。
- subagent background mode 是否首版启用需由 feature flag 决定。
