# Interface CLI/HTTP 架构设计

## 1. 职责与边界

本上下文负责 CLI/TUI 命令入口、HTTP API、SSE、PTY WebSocket、OpenAPI/SDK 生成、auth、CORS、workspace routing 和错误响应格式。不包含业务规则。

上游证据：`packages/opencode/src/index.ts`、`server/routes/instance/httpapi/`、`packages/sdk/js/src/v2/gen/`。

## 2. 核心概念

| 类型 | 名称 | 说明 |
|---|---|---|
| 值对象 | `HttpRouteId` | operationId，如 `session.prompt`。 |
| 值对象 | `CliCommandId` | yargs command 字符串等价 ID。 |
| 值对象 | `AuthPrincipal` | Basic Auth / local desktop principal。 |
| 领域服务 | 无 | interface 不放领域服务，只调用 application use case。 |

## 3. 模块拓扑

| 层 | 模块 |
|---|---|
| domain | 无 |
| application | use case facade traits |
| infrastructure | auth password store、OpenAPI patcher、SSE encoder、WS upgrader |
| interface | `cli/`、`http/`、`sse/`、`ws/pty.rs`、`sdk_codegen/` |

## 4. 对外契约

- HTTP 131 个端点以 [HTTP 清单](../../research/opencode-upstream-analysis/附件/http-api-inventory.generated.md) 为规划基线。
- CLI 33 个命令模块以 [CLI 清单](../../research/opencode-upstream-analysis/附件/cli-command-inventory.generated.md) 为规划基线。
- OpenAPI 必须兼容 `packages/sdk/openapi.json` 和 `packages/sdk/js/src/v2/gen/types.gen.ts`。
- SSE：`GET /event`、`GET /global/event`。
- WS：`GET /pty/:ptyID/connect?ticket=...`。

## 5. 关键不变量

- 默认无子命令启动 TUI，不等价于 `run`。
- Basic Auth：username 默认 `opencode`，password 来自 env/desktop sidecar，未配置时遵循上游本地策略。
- `directory/workspace` query 和 `x-opencode-directory/x-opencode-workspace` header 兼容。
- schema error response 必须含字段路径。
- `public.ts` 中的 OpenAPI 兼容修正必须在 Rust OpenAPI patcher 中复刻。

## 6. 错误模型

| 错误 | 类型 | 场景 |
|---|---|---|
| `Unauthorized` | interface | Basic Auth 失败。 |
| `BadRequest` | interface | params/query/payload schema 失败。 |
| `NotFound` | interface/application | 聚合不存在。 |
| `Conflict` | application | session busy 等冲突。 |
| `Internal` | infrastructure | 未分类 I/O 错误，需脱敏。 |

## 7. 扩展点

- 新 HTTP 端点先更新 development 接口设计和 OpenAPI snapshot。
- 新 CLI 命令必须补 help snapshot 和 shell completion。

## 8. 未决问题

- Rust TUI 与现有 JS TUI 的过渡策略需单独 ADR。

## 9. M1 实现落位 — 2026-05-28

- `opencode_server` 采用 `axum` 暴露最小 router：`GET /global/health` 与 `GET /openapi.json`。
- `serve(listener, CancellationToken)` 支持 graceful shutdown，后续 CLI/Desktop sidecar 复用同一入口。
- M1 OpenAPI 只覆盖 health/openapi 两个 operation；131 endpoints 的完整 codegen 仍以后续 contract inventory/diff 为准。
- TypeScript SDK 先由仓库内 `generate_typescript_sdk()` 生成最小 `client.ts`/`index.ts`，不在 M1 引入外部 OpenAPI generator。
